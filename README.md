Продающий сайт по реставрации ванн жидким наливным акрилом класса «Люкс».

## 🚀 Настройка Яндекс.Метрики:
1. Создайте счетчик в [Яндекс Метрике](https://metrika.yandex.ru/).
2. В файле `index.html` раскомментируйте блок счетчика в `<head>` и вставьте номер счетчика вместо `XXXXXXXX`.
3. В файле `js/main.js` укажите ваш номер счетчика в переменной `const YANDEX_METRIKA_ID = 12345678;`.

### Цели для Яндекс.Директа:
- `hero_calc_submit` — отправка расчета из калькулятора в шапке
- `side_direct_submit` — отправка формы консультации
- `modal_callback_submit` — заявка из модального окна
- `click_phone` — клик по номеру телефона
- `click_viber` — переход в чат Viber
- `click_telegram` — переход в чат Telegram
- `click_whatsapp` — переход в чат WhatsApp
- `quiz_interact` — взаимодействие с параметрами ванны
