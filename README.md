# Реставрация ванн в Полоцке и Новополоцке (Мастер Денис Леташков)

Продающий бизнес-лендинг по реставрации ванн жидким наливным акрилом класса «Люкс».

## 🌟 Ключевые особенности сайта:
- **Чистый, вызывающий доверие дизайн**: ориентирован на реальных клиентов и максимальную конверсию без лишней перегрузки.
- **Интерактивный экспресс-калькулятор (квиз)**: моментальный расчет стоимости под размер и состояние ванны с фиксацией скидки.
- **Интерактивный слайдер «До / После»**: плавное перетягивание шторки для наглядного сравнения результата работы.
- **Мобильный плавающий бар (Sticky Call Bar)**: моментальный звонок и переход в Viber/Telegram/WhatsApp в один клик с мобильных телефонов (дает максимальную отдачу из рекламы в Яндекс.Директ).
- **Продвинутое SEO (Google & Яндекс)**:
  - Микроразметка `Schema.org` (`HomeAndConstructionBusiness`, `LocalBusiness`, `Service`, `FAQPage`, `AggregateRating`);
  - Мета-теги OpenGraph, Twitter Cards, географические мета-теги Полоцка/Витебской области;
  - Файлы `robots.txt` и `sitemap.xml`;
  - Семантическая разметка HTML5.
- **Готовность к Яндекс.Директ и Яндекс.Метрике**:
  - Настроенные автоматические события (`reachGoal`):
    - `click_phone` — клик по телефону
    - `click_viber` — клик по Viber
    - `click_telegram` — клик по Telegram
    - `click_whatsapp` — клик по WhatsApp
    - `calc_submit` — отправка расчета из калькулятора
    - `callback_submit` — отправка формы обратного звонка
    - `quiz_interact` — взаимодействие с параметрами ванны

---

## 🚀 Как включить Яндекс.Метрику:
1. Создайте счетчик в [Яндекс Метрике](https://metrika.yandex.ru/).
2. В файле `index.html` раскомментируйте блок счетчика в `<head>` и вставьте номер счетчика вместо `XXXXXXXX`.
3. В файле `js/main.js` укажите ваш номер в переменной `const YANDEX_METRIKA_ID = 12345678;`.
